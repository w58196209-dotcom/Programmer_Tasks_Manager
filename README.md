# لعبة عالم مفتوح

لعبة بسيطة من نوع عالم مفتوح مبنية باستخدام HTML وCSS وJavaScript.

## التشغيل

1. افتح مجلد المشروع.
2. قم بتشغيل خادم ثابت، مثل:
   ```bash
   python -m http.server 8000
   ```
3. افتح المتصفح على:
   ```text
   http://localhost:8000
   ```

## التحكم

- WASD أو الأسهم: الحركة
- E: التفاعل مع الأشخاص

## الهدف

- جمع 3 أعشاب في العالم.
- العودة إلى رئيس القرية.
- استكشاف العالم واستلام مكافأة.
